# 站内内容更新提示

每个公开页面顶部都有「内容更新」栏，适配桌面和手机。页面打开且可见时每分钟检查一次，回到页面时也会检查；可点「检查更新」立即查询。

- 有未查看更新时显示总数，并列出文章与报告数量。打开更新栏即可查看最新标题，直接进入文章、日报、周报或月报，同时将当前这一批标记已查看。
- 最近公开更新时间使用站内发布／修订时间，不用旧论文的原始发表日期冒充今日发布。文章分类、归组等公开信息变化也可能计为一次更新，同一篇文章在一次查询中只计一次。
- 只统计最近 30 天已公开、可读的内容，列表展示最新 12 条，数量按完整窗口计算。已公开补录资料也可提醒；仅抓取入库、被拦截、尚未放行的精选、撤回文章和空报告均不提醒。
- 首次打开建立查看基线，仍可展开浏览近期标题，不将全部历史文章标成未读。以后重新打开同一浏览器会继续比较上次查看记录；多个标签页同步查看进度。
- 查看时间保存在当前站点的浏览器存储里，没有账号同步。清除浏览器数据、更换浏览器或无法写入存储时，重新建立基线。
- 断网或 API 暂时不可用时保留上次结果，显示失败提示，稍后重试。它显示公开内容变化，不是 worker 健康监控；电脑、Docker 或网页关闭时不会发送桌面、邮件或手机推送。

## 已有 Windows 试运行升级

已完成信源扩充的用户只需更新代码与镜像，无需重装信源或再次 prepare：

```powershell
cd D:\Projects\agent-eval-radar
docker compose stop worker
git -c http.proxy=http://127.0.0.1:7897 -c http.version=HTTP/1.1 pull --ff-only origin feat/agent-eval-v0.1
docker compose build api
docker compose up -d --no-deps api web
docker compose -f docker-compose.yml -f industry/v0.1/compose.auto-trial.yml up -d --no-deps worker
```

在浏览器重新加载网站，顶部出现「内容更新」栏。首次进入点击展开即可看到最近公开的文章与报告。安全阀、试运行到期时间、请求预算、原有数据与评分门槛保持不变。

## 实现与验证

接口 `GET /api/site/updates?since=<ISO时间>` 由统一 `publication/` 读取层提供，只返回标题、站内链接、更新时间和数量，不返回正文、后台状态或密钥；响应不缓存。通知查询不触发模型调用，也无需数据库迁移。

回归覆盖首次基线、查看记录持久化、跨标签页同步、页面隐藏、断网保留与恢复、文章／报告链接，以及公开门控、撤回、空报告、时间边界和修订计数。UI 回归运行真实 React 组件与浏览器 DOM 替身，API 与数据库回归使用临时测试库；不调用外部付费服务。
